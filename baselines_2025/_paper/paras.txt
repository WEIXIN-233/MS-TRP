与关系证据分析
[P1] Normal :: MS-TRP：多尺度时序风险建模与关系证据分析
[P2] Normal :: 摘要：预算执行支付数据具有多尺度时序变化、异构实体关联与信息延迟与可读性约束等特征，单一阈值规则难以同时覆盖不同异常模式并控制复核负担。本文提出多尺度时序与关系风险传播模型 MS-TRP。模型在七日、三十日、当季和当年四个尺度上构造金额、频次及执行进度特征，结合个体历史与同类群体建立稳健参照；利用九类业务实体构造阶段感知异构图，以个性化回跳传播扩散已有风险；通过可靠度门控融合时序与关系分数，并在验证集校准后冻结分层告警阈值，输出特征、历史、规则与关系四类审计证据。在包含85,330条支付记录的合成预算数据上，采用2023—2024年训练、2025年验证及2026年测试的时间划分。MS-TRP的测试集Payment-AUPRC为0.4649，低于Concat-IF的0.4863与Isolation Forest的0.4786，冻结阈值下精确率为0.8591、召回率为0.0507；在10%误报率下，召回率为0.5530。消融结果表明，当前多尺度组合优于单尺度变体，构成整体排序性能的主要来源，图传播未带来整体AUPRC提升，其作用主要体现为部分实体聚集异常的风险扩散。实验揭示了风险排序、阈值告警与事件检出的差异，为预算执行异常监控提供了可解释的建模与评价方案。结论适用于本文合成场景，独立生成机制对照显示模型仍有效但增益收窄，仍需真实业务数据验证。
[P3] Normal :: 关键词：预算执行；异常检测；多尺度时序；时间可追溯；关系证据分析；误报控制
[P5] Heading 1 :: 1 引言
[P6] Normal :: 预算执行监控需要从持续产生的支付申请、预算指标、支付凭证和收款账户中识别值得复核的异常。异常可能体现为单笔金额偏离，也可能表现为短期付款频率上升、执行进度持续滞后或跨项目共享交易实体。金额较大的采购、正常年末结算及合法公共供应商又可能形成相似观测，因此，将统计偏离直接等同于违规事实并不适当。检测模型的作用是提供风险排序与证据线索，为后续人工核查分配有限资源。
[P7] Normal :: 异常检测通常依据数据对正常行为假设的偏离程度识别异常[1]。在预算执行场景中，正常行为具有明显的时间与业务条件依赖。同一项目在启动期与年末的付款节奏不同，同一金额在不同类别项目中也具有不同含义。此外，业务字段的发生时间与系统可读时间可能不一致。若在历史评分中使用事后补录信息，离线结果将高估实际可用的检测能力。
[P8] Normal :: 现有通用表格检测器能够刻画特征空间中的离群程度，但其效果取决于输入是否表达业务时序与实体关系。Isolation Forest通过随机划分隔离样本[2]，LOF通过局部密度差异衡量离群程度[3]。这类方法并不自动提供多时间尺度参照，也不直接区分业务边方向与风险传播方向。另一方面，关系扩散可以连接共享收款人或账户的多个项目，但共享关系本身并不必然意味着异常。
[P9] Normal :: 与通用表格异常检测相比，预算执行监控存在四类业务差异。其一为阶段异质性：同一项目在启动期以小额勘察与招标费用为主，建设与验收期出现大额工程款，年末又产生集中结算，跨阶段的金额与频次基线并不相同。其二为合法共享关系：集中采购平台、公共财政银行账户与长期供应商会同时连接大量项目，共享收款人或账户本身不能作为异常证据。其三为信息延迟可读：支付申请、凭证与业务字段的发生时间与系统可读时间可能不一致，事后补录若进入历史评分会高估实际可用的检测能力。其四为复核预算：人工复核名额有限，模型输出必须支持按风险排序并在给定误报预算内分配复核，而非仅给出单一阈值告警。通用表格检测器通常未同时刻画这四类条件，因此需要面向预算执行的建模与评价方式。
[P10] Normal :: 本文围绕上述问题构建MS-TRP，研究评分时点约束下的多尺度稳健偏离、关系传播与可靠度融合。本文的贡献分为三个层面：一是提出时间可追溯的分析架构，将多尺度稳健时序参照、关系传播、可靠度门控与分层阈值组织为可回放的风险分析流程（图1）；二是通过消融识别各组件效益，表明多尺度表示是整体排序性能的主要贡献来源，而图传播未带来整体AUPRC提升（表7）；三是确立支付级排序、冻结阈值告警与事件级检出相互区分的评价协议，以统一口径界定适用范围（表4—表6）。本文不预设完整模型优于所有基线。
[P11] Heading 1 :: 2 相关工作
[P12] Heading 2 :: 2.1 表格异常检测
[P13] Normal :: 基于隔离、密度、稳健协方差和聚类的方法提供了不同的异常假设。Isolation Forest关注随机划分下的隔离路径长度[2]，LOF关注邻域密度相对差异[3]，最小协方差行列式估计通过稳健位置与散布识别多变量偏离[4]，CBLOF结合聚类结构描述局部离群程度[5]。这些方法适合作为统一特征接口下的对照，但不能将某一特征工程组合的收益全部归因于检测器本身。
[P14] Normal :: ECOD通过各维经验分布估计尾部概率[6]，COPOD通过经验Copula构造多变量离群分数[7]。两者能够在较少超参数设置下处理表格数据。PyOD为多种检测器提供一致的软件接口[9]。本文将原始白名单输入与MS-TRP派生特征输入加以区分，主对照采用原始输入，组合式Concat-IF用于观察派生表示与隔离检测的联合效果。大规模表格异常检测的系统比较可参考ADBench基准，其统一57种检测器与30个数据集提供可复现的对照结果[12]。
[P15] Heading 2 :: 2.2 可靠时序异常评测
[P16] Normal :: 类别不平衡条件下，精确率—召回率分析能够直接呈现阳性预测中的真实异常比例[10]。时间序列异常还涉及持续区间与事件匹配，单点命中不等同于完整事件检出。VUS系列指标通过扩展阈值无关评价考虑区间偏移等因素[11]。本文以Payment-AUPRC作为支付级主指标，同时报告误报预算约束下的召回与事件级指标，避免仅由单一工作点得出总体优劣结论。在可靠评测层面，TSB-AD整理40个数据集与1070条人工校验时间序列，指出点调整等评测偏差并推荐VUS-PR等可靠指标[13]；TAB面向多变量与单变量时序构建统一自动化评测管线，覆盖非学习、机器学习、深度学习与LLM方法[14]。
[P17] Heading 2 :: 2.3 动态异构图与关系传播
[P18] Normal :: PageRank利用图连接结构构建迭代评分机制[8]。在异常检测中，可将已有异常分数作为个性化种子，使风险沿允许的关系传播。该操作的作用是重新分配已存在的风险信息，而非在全零种子下产生新的异常证据。因此，关系传播是否有效依赖于种子质量、边的业务语义以及正常共享关系与异常共享关系的可区分程度。
[P19] Normal :: 预算业务具有单位、项目、指标、凭证、收款人及账户等多类型实体。业务边记录资金链条的实际方向，风险追踪却可能需要沿共享实体返回其他项目。本文分别维护业务边与传播边，保留原始时间和方向，同时为允许的消息交换建立双向边，避免混淆交易事实与分析用途。
[P20] Heading 2 :: 2.4 财政与审计数字化
[P21] Normal :: 在公共预算数据上，已有工作利用机器学习识别预算计划数据中的离群情形，说明该领域存在统计异常检测的实际需求[15]。该研究以预算编制与计划数据为对象，与本文对预算支付凭证执行过程的风险识别属于不同任务层次。本文的评分对象限定为已形成且可读的支付凭证，不将预算计划离群识别外推为支付合规验证。

[P49] Heading 2 :: 4.2 阶段感知异构图风险传播
[P50] Normal :: 在评分时点构建仅包含已可读实体和关系的异构图。业务边保留凭证到收款人、收款人到账户等实际记录方向；传播边则依据允许的业务关系提供双向消息方向，使一个项目的已有风险能够经共享实体传递至其他项目。关系构造不使用注入事件标签。
[P51] Normal :: 九类图节点为项目、预算指标、支付申请、支付凭证、收款人、品目、账户、单位与支出分类。业务边按实际记录方向连接相邻实体：申请生成凭证，凭证指向收款人与品目，收款人归入账户，项目关联申请与指标，指标与单位建立归属。传播边在业务关系上补充反向消息边，使一个项目的已有风险可沿共享收款人、共享账户或共享指标向其他项目传递；业务边方向与消息边方向相互独立，具体边白名单由配置表固定，不随测试标签调整。

[P128] Heading 1 :: 7 讨论与局限性
[P129] Heading 2 :: 7.1 排序能力与告警能力的边界
[P130] Normal :: 本文结果呈现三种不同层面的性能。Payment-AUPRC衡量整体分数排序，固定误报率召回衡量指定误报率下的检出能力，冻结阈值指标反映既定部署工作点。MS-TRP在10%误报率下具有较高召回，但在5%误报率下并不占优，冻结阈值下召回更低。因此，其应用需根据可接受复核量选择并验证工作点，不能仅凭精确率作全面有效性判断。
[P131] Normal :: Temporal-only的正常样本中存在超过目标比例的分数饱和，导致正常分数高分位点取到上界1.0。严格大于阈值的规则不产生告警，使FAR与事件指标为零，但其排序指标仍然可以计算。完整模型的融合改变分数分布后避免了同样的上界退化。该差异反映分数与阈值接口的数值性质，不能单独作为关系分支提升异常辨识力的证据。
[P132] Heading 2 :: 7.2 关系风险与结构种子的限制
[P133] Normal :: 图传播依赖时序种子。当共享收款人或账户没有独立异常种子时，传播只能重分配相邻支付风险，不能仅凭共享结构生成风险。对合法公共供应商与异常资金聚集，二者可能具有相同的高连接度，简单提高共享边权会同时增加正常交易风险。后续应构造独立结构证据，并在保持相同输入权限和时间边界的条件下检验其增量价值。
[P134] Normal :: 当前源头实体自身时序种子为零，且桥接支付与受影响支付的标识未形成可区分分组，因此无法从现有诊断中验证异常源头定位。本文将关系证据限定为可回查的关联路径，不宣称通过PPR识别真实资金风险源头。
[P135] Heading 2 :: 7.3 合成数据与复现限制
[P136] Normal :: 全部实验基于同一生成机制下的合成预算数据。异常模式和正常对照虽体现业务约束，但其边际分布、关联结构与人工定义仍可能使特定方法受益。单次主结果缺少跨数据种子、跨生成器与真实业务验证，不能据此作真实财政部署有效性的结论。本文报告数值差异，不对较小差异使用显著性措辞。为检验投稿论断对生成机制的依赖性，另构建独立生成器B：其年度节奏采用对数正弦基波加二次谐波，正常支付金额采用独立对数正态抽样（不强制月内预算守恒），六类异常分别替换为加性金额偏移、十日窗口频次突增、幂律光滑进度滞后、十一至十二月集中、循环相位平移与实体重连等机制。在三组数据种子下与生成器A对照：A的AUPRC均值为0.4590（区间0.4375至0.4854），B为0.3510（区间0.3456至0.3553），跨机制跌幅23.53%。B机制下AUPRC仍约为测试集阳性率的2.2倍，表明模型跨机制仍保持明显优于随机的能力，但增益收窄约四分之一，故投稿论断宜表述为跨机制部分成立、需限缩。
[P137] Normal :: 冷启动结果尚缺组内阳性率，鲁棒性结果缺少重复扰动区间，运行时间与内存开销也未形成统一实测对照。方法中的窗口权重、门控温度、关系衰减与完整变体开关需要随实现配置共同归档，才能支持精确复算。后续研究应补充独立数据源、完整配置、逐样本预测和校准诊断，并对图分支与规则通道进行更严格的单因素验证。
[P138] Heading 1 :: 8 结论
[P139] Normal :: 本文提出面向预算执行异常检测的MS-TRP模型，将多尺度稳健时序参照、异构图关系传播、可靠度门控与分层阈值校准组织为可追溯的风险分析流程。合成实验中，模型Payment-AUPRC为0.4649，冻结阈值下精确率为0.8591、召回率为0.0507、FAR/1000为1.39，10%误报率下召回为0.5530。结果表明，整体排序与告警覆盖需要分别评价，多尺度组合是当前场景的主要贡献来源。
[P140] Normal :: 图传播未改善整体AUPRC，在部分实体聚集事件上提供了有限增量，规则通道仍承担较大检出作用。模型对历史不足样本的组内表现较好，但长历史场景、事件覆盖和严格误报预算下仍有不足。未来应围绕独立结构种子、跨生成机制验证、真实业务数据与可复现配置开展研究，以进一步界定该框架的适用条件。
